# Digit templates

`digits.json` contains normalized 24×36 binary glyphs and their original aspect
ratios. Labels were taken from the manually verified unsolved Level 2 reference
provided by the user. Both cell digits and the larger target digits are included;
the target `10` supplies the zero glyph. No desktop content is included.

These are fixed font samples, not puzzle answers. Runtime recognition never
updates them from OCR predictions. Levels 3–5 and the 8×8 Level 7 are held-out
regression images.
